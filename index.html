Gmail MCP

Home · Privacy Policy · Terms of Service

Gmail MCP is a personal, self-hosted tool that runs only on its owner's own computer. It lets the owner use several of their own Gmail accounts from the Claude desktop app through the Model Context Protocol (MCP).

It is not a public service: there is no sign-up, no server operated by the developer, and no data is sent anywhere except directly between the owner's computer and Google.
